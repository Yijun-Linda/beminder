## 迭代目标

iPhone App 作为 BLE（Bluetooth Low Energy，低功耗蓝牙）主设备（Central），扫描、发现并连接 FoloToy，把 Session 状态写入设备。

## Bug 追踪

### 2026-08-22：闭包内误用 session 而非 self.session

现象：observeFoloToy 与 observeFoloToyConnection 的闭包里直接写 `session.state` / `session.foloToyConnected`，未加 self 前缀。

根因：NotificationCenter closure 里有 `guard let self`，但在其中一处漏用 self 访问实例属性。

修复：SessionManager 中统一用 self.session，闭包内均通过 self 访问。

验证：静态核对所有 self 捕获与属性访问。IOS 无真实编译环境，需在 Mac/Xcode 真机验证，Android/Windows 不适用。
